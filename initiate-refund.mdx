---
title: "Initiate Refund"
---

The **Initiate Refund** endpoint (`/v2/order/command` with `transactionType: "REFUND"`) allows merchants to initiate a full or partial refund for a successfully completed payment. The amount is reversed directly back to the customer's original payment source.

---

| **Environment** | **HTTP Method** | **API** |
| :-- | :-- | :-- |
| `Sandbox` | `POST` | [https://api-uat.originpay.in/v2/order/command](https://api-uat.originpay.in/v2/order/command) |
| `Production` | `POST` | [https://api.originpay.in/v2/order/command](https://api.originpay.in/v2/order/command) |

## 1. Endpoint Details

| Attribute | Value |
| --- | --- |
| **URL** | `/v2/order/command` |
| **Method** | `POST` |
| **Content-Type** | `application/json` |
| **Authentication** | Basic Token (Authorization Header) |

---

## 2. Required Headers

| Header | Value | Description |
| --- | --- | --- |
| `Authorization` | `Basic <basic_token>` | Basic token generated from `/v2/auth/token` or `base64(public_key:secret_key)` |
| `X-MERCHANT-ID` | `<your_merchant_id>` | Unique merchant identifier |
| `Content-Type` | `application/json` | Required for JSON request bodies |

---

## 3. Request Body

The request must be sent in JSON format.

### Request Fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `merchantOrderId` | string | Yes | Unique order identifier of the original completed payment (`merchant_order_id` is also accepted) |
| `amount` | number | Yes | Refund amount in paise (1 INR = 100 paise). Range: 1 to original transaction amount |
| `transactionType` | string | Yes | Must be `"REFUND"` (`transaction_type` is also accepted) |
| `remark` | string | No | Reason or note for the refund (max 255 characters) |

---

### Request Example

```json
{
  "merchantOrderId": "ORDER12345",
  "amount": 50000,
  "transactionType": "REFUND",
  "remark": "Customer requested order cancellation"
}
```

---

## 4. Success Response

**Status Code:** `200 OK`

```json
{
  "success": true,
  "statusCode": 200,
  "txnStatus": "SUCCESS",
  "message": "Refund initiated successfully",
  "data": {
    "merchant_order_id": "ORDER12345",
    "order_id": "ord_100000045",
    "refund_id": "ref_9000001",
    "refund_amount": 50000,
    "currency": "INR",
    "refund_status": "processed",
    "created_at": "2026-10-30 05:30:00"
  }
}
```

---

## 5. Implementation Example

### JavaScript (Fetch)

```javascript
const requestBody = {
  merchantOrderId: "ORDER12345",
  amount: 50000,
  transactionType: "REFUND",
  remark: "Customer cancellation"
};

const response = await fetch("https://api.originpay.in/v2/order/command", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Basic YOUR_BASIC_TOKEN",
    "X-MERCHANT-ID": "YOUR_MID"
  },
  body: JSON.stringify(requestBody)
});

const result = await response.json();
```

---

## Important Notes

- Refunds can only be initiated against transactions that have a successful status (`SUCCESS`).
- The `amount` must always be sent in paise (e.g. ₹500.00 = `50000`).
- Once a refund is initiated, the funds will be credited back to the customer's source account according to banking settlement timelines (instant for UPI, 3–7 business days for Cards and Net Banking).
- In the event of system maintenance, the endpoint will return status `503` with message `"refund apis is currently down for maintanance"`.
